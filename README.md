# 基金分批加仓助手

一个适合手机使用的个人基金监控网页。数据由 GitHub Actions 自动更新，页面由 GitHub Pages 免费托管，不需要购买域名或服务器。

访问地址：`https://china1240695852-source.github.io/fund-monitor/`

## 当前配置

- 场外基金：016707 华夏有色金属 ETF 联接 A
- 目标 ETF：516650 有色金属 ETF 华夏
- 计划预算：1000 元
- 默认 5 档、每档下跌 5%
- 递增预算默认约为 100、150、200、250、300 元，也可以逐档手动修改

页面只提供监控、预算和买入记录功能，不会自动交易，也不包含短信、微信或 PushPlus 提醒。

## 使用方法

打开网页后，可以修改总预算、档位数、档位间隔、起算净值、已有份额和累计成本。点击“重新自动生成”计算档位；每一档的触发净值和金额都可以手工微调。实际买入后点击该档的“记录买入”，网页会在当前浏览器保存持仓和执行状态。

持仓数据只保存在当前设备的浏览器中，不会上传到 GitHub。建议使用页面里的“导出备份”定期保存；换手机时用“导入备份”恢复。

## 更换或增加基金

在 `data` 目录新增或修改 JSON 文件。例如：

```json
{
  "username": "china1240695852-source",
  "funds": [
    {
      "code": "016707",
      "name": "华夏有色金属ETF联接A",
      "etf_code": "sh516650",
      "defaults": {
        "budget": 1000,
        "level_count": 5,
        "step_pct": 5,
        "allocation": "increasing"
      }
    }
  ]
}
```

沪市 ETF 使用 `sh` 前缀，深市 ETF 使用 `sz` 前缀。提交配置后，自动任务会刷新 `docs/data.json`，网页会自动显示新增的基金标签。

## 自动更新

- 交易日北京时间 09:00–15:30 左右，每 30 分钟刷新一次 ETF 盘中行情
- 交易日北京时间 21:10 再刷新一次场外基金官方净值
- GitHub 的定时任务可能延迟几分钟，数据源接口变化时也可能暂时不可用

## 本地运行

```powershell
py fetch.py
py -m http.server 8000 --directory docs
```

然后打开 `http://localhost:8000`。

> 本项目仅用于个人记录和辅助决策，不构成投资建议。基金和 ETF 有价格波动及本金亏损风险；页面显示“触发”也应由使用者自行判断是否买入。
